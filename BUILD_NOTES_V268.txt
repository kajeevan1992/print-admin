# v268 — Customer Task Ownership + Assignment

Base: v267 customer task SLA/escalation ZIP.

## Added
- Customer task ownership and assignment layer.
- New internal route: `/api/internal/catalog/customer-task-assignments`.
- Default internal assignee pool:
  - Support Lead
  - Artwork Desk
  - Production Coordinator
  - Dispatch Desk
- Assignment actions:
  - Assign Next
  - Assign Support
  - Unassign
- Assignment workload summary:
  - assigned tasks
  - unassigned tasks
  - active assigned tasks
  - overloaded assignees
- Assignment actions write internal communication notes.
