What changed:
- Added internal production-flow endpoint:
  - GET /api/internal/catalog/production-flow
  - POST /api/internal/catalog/production-flow
- POST creates a production job from an existing storefront order pipeline record.
- Production job validation checks:
  - orderId is required
  - pipeline order exists
  - line items exist
  - customer details exist
  - pricing exists on all line items
  - artwork is received before production job creation
- Production job stores:
  - job number
  - linked order number / order id / draft id
  - customer
  - line items
  - totals
  - artwork status
  - turnaround
  - delivery estimate
  - prepress queue stage
  - audit trail
- Existing order pipeline record is updated to:
  - status: in-production
  - pipelineStage: production
  - productionStatus: prepress-queue
  - productionJobId / jobNumber
