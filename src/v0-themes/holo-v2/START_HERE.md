# Start here

This is the safe HOLO V2 presentation-only theme package.

For v0 work, share only:

```text
src/v0-themes/holo-v2/
src/v0-themes/contracts.ts
```

Do not give v0 the full repository and do not ask it to edit pricing, VAT, checkout, orders, database code, API routes or environment variables.

The current starter is deliberately not connected to the live HOLO storefront. Atlantis remains unchanged until the completed HOLO V2 package is reviewed, installed, deployed, selected as a draft and manually published from the Storefront Builder.
