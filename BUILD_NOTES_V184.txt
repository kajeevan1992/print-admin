Build: v184 product templates + option override foundation

Scope completed:
- Added a Templates & Rules tab inside the existing product edit page.
- Added reusable setup presets for Business Cards, Booklets, PVC Banners and Boards/Rigid Media.
- Added product-level merge/override mode:
  - use template only
  - merge template + product overrides
  - product custom setup only
- Added pricing/production hook fields only, no pricing engine logic:
  - pricing profile key
  - production method
  - source sheet/roll width and length
  - max printable width and length
  - internal notes for later pricing rules
- Added artwork rule fields:
  - allowed file types
  - min/max files
  - required page count
  - bleed
  - require PDF
  - allow design from template
  - customer instructions
- Extended option groups with:
  - info-cards display style
  - pricing key per group
  - pricing key per value
  - customer help text
- Product preview now reads template/artwork rules when present.
- Product template rules are persisted in existing product metadata storage.

Important:
- This build does not add pricing calculations.
- This build does not redesign admin UI or storefront theme.
- This build does not copy WordPress plugin code.
- Plugin ideas were converted into SaaS-native config fields only.
